# AI × 新质生产力 / AI as New Quality Productive Force

一个可直接部署到 GitHub Pages 的数据叙事型交互网站。

## 文件
- `index.html`：页面结构、双语文本、数据来源
- `styles.css`：响应式视觉设计、动画、暗色模式
- `app.js`：交互、图表、语言切换、主题切换、滚动动画

## 主要亮点
1. “生产力引擎”滑块：模拟 AI 从辅助到智能系统的介入深度。
2. KPI 数据看板：AI 投资、组织采用率、生成式 AI 普及、推理成本。
3. 行业交互：制造、医疗、教育、科研、物流五个场景。
4. “工具 → 流程 → 系统”的生产力跃迁叙事。
5. 创造 / 赋能 / 约束三栏，避免把 AI 简化成单纯自动化。
6. 中英双语、响应式布局、暗色模式、滚动进度与动画。
7. 不依赖 React/Vue/Node，直接上传静态文件即可运行。
